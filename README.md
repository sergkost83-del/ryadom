# РЯДОМ

Цифровая платформа для жителей жилых комплексов: соседские чаты, парковка, совместные поездки (Попутчик), обращения.
Пилот — ЖК в Буграх (Ленинградская область).

Статус: **0.8.0.dev2 — идёт этап M1** (фундамент): готов серверный вход, регистрация и профиль; экранов пока нет.
План и критерии готовности: [`docs/M1_ACCEPTANCE.md`](docs/M1_ACCEPTANCE.md). Архитектура: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Как проверить проект (без технических знаний)

1. Дважды щёлкните `CHECK_ALL.bat` — получите отчёт `reports/REPORT.md` (откроется сам).
2. После отправки изменений в GitHub автоматически запускаются полные тесты: вкладка **Actions** → последний запуск → зелёная галочка или красный крестик, внизу страницы запуска — сводка на русском.

## Как запустить для разработки (нужен Docker)

```
copy .env.example .env
docker compose up --build
```
Сервер: http://127.0.0.1:8000/api/v1/health/ . Тесты: `docker compose --profile test run --rm --build tests`.
