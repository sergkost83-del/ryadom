# Клиент «РЯДОМ» (Expo, TypeScript)

Одно приложение для iPhone, Android и веба. Папка `client/`.

## Экраны первой версии
- Вход: приветствие → e-mail → код из письма → (для нового пользователя) регистрация.
- Регистрация: имя, выбор дома по шагам (ЖК → улица → дом) или код приглашения, подтверждение 18+, согласия.
- Главная: статус адреса (нет, на проверке, подтверждён), объявления дома, принятие новых версий документов.
- Профиль: аватар, имя, телефон, адрес и заявка на смену, устройства (выход на любом устройстве и везде), мои данные (просмотр и сохранение), удаление аккаунта.
- Тексты политики и согласия — **черновики** до утверждения юристом.

Правило: в приложении только работающие функции. Разделы без серверной части (чаты, парковка, Попутчик) появятся вместе с готовой функцией.

## Устройство
- `app/` — экраны (Expo Router). `src/api/` — запросы к серверу и разбор ошибок. `src/auth/` — токены и состояние входа. `src/ui/` — общие компоненты. `src/*.ts` — проверки ввода, адреса, форматирование.
- Токен доступа обновляется автоматически; при нескольких параллельных запросах делается один обмен (токен обновления одноразовый).
- На телефоне токены в защищённом хранилище системы; в вебе в `localStorage`.

## Запуск для разработки
```
cd client
npm run assets          # копирует изображения из design/assets
npm install
EXPO_PUBLIC_API_URL=http://localhost:8000 npx expo start
```
Для веба без указания адреса запросы идут на тот же адрес, откуда открыт сайт (в проде это Caddy: сайт и `/api` на одном домене).

## Проверки
`npm run typecheck`, `npm test` (38 тестов логики), `npx expo export --platform web` (сборка веба). Всё выполняется в GitHub Actions (задание «Клиент»). Файл `package-lock.json` прикладывается к запуску: его нужно закоммитить, чтобы зафиксировать версии.
