# Критерии готовности M1

M1 готов, когда CI зелёный, а записанные автотестами сценарии показывают все пункты. Статус: ☐ не начато, ◐ в работе, ☑ готово.

| № | Критерий | Статус |
|---|---|---|
| 1 | **Регистрация:** e-mail → код → имя → «мне 18 лет» → ЖК и дом → политика и согласие → профиль. Отказ без 18+, без согласия, при неверном/просроченном/повторном коде | ◐ сервер готов, экраны — позже |
| 2 | **Защита входа:** лимиты запросов кода и попыток; код не возвращается в ответе API | ☑ (проверяется тестами) |
| 3 | **Вход с другого устройства:** тот же e-mail → код → существующий аккаунт; независимые сессии; «выйти здесь/везде»; старый токен не работает | ☑ сервер (экраны — позже) |
| 4 | **Профиль:** имя, аватар, необязательный телефон; чужой профиль недоступен; имя с `<` и `>` не принимается | ☑ сервер (экраны — позже) |
| 5 | **Согласия:** версия и время принятия; отзыв; повторное принятие при новой версии | ◐ принятие при регистрации готово; отзыв и повторное принятие — следующий блок |
| 6 | **Удаление и экспорт:** экспорт всех данных; удаление с отложенным стиранием | ☐ |
| 7 | **Сообщества:** справочник загружен (3 ЖК, 23 дома); адрес закреплён; смена только через заявку | ◐ справочник и модели готовы |
| 8 | **Разграничение доступа:** роли; тесты «житель дома A не видит дом B»; админка только для сотрудников с 2FA | ☐ |
| 9 | **Миграции:** чистая БД с нуля; обновление без потери данных; откат проверен | ◐ проверка согласованности в CI |
| 10 | **Безопасность по умолчанию:** закрытый CORS, заголовки, нет секретов, зависимости без критичных уязвимостей | ◐ `check --deploy`, `pip-audit`, поиск секретов |
| 11 | **Клиент:** экраны по макетам (Expo, веб), сценарии 1–4 проходят в браузере в автотесте | ☐ |
| 12 | **Покрытие тестами** модулей identity и communities не ниже 85% | ☐ (сейчас порог 80%) |
