# Руководство главного администратора

## Первый вход
1. На сервере создайте главного администратора: `python manage.py createsuperuser` (e-mail и пароль не короче 12 символов).
2. Войдите на страницу админки. Система предложит настроить двухфакторную защиту: отсканируйте QR-код в приложении-аутентификаторе (например, Яндекс Ключ) или введите ключ вручную, затем введите код из приложения.
3. **Сохраните 10 резервных кодов** (показываются один раз). Каждый работает один раз.
4. Выполните `python manage.py setup_roles` (создаёт группу «Модераторы»).

## Как назначить модератора
1. Модератор регистрируется в приложении как обычный житель.
2. В админке: «Привязки модераторов» → добавить: выберите его и ЖК. Роль модератора и доступ в админку выдаются автоматически.
3. При первом входе в админку модератор настраивает свою двухфакторную защиту и сохраняет резервные коды.
4. Несколько модераторов на один ЖК: добавьте отдельную привязку для каждого.
5. Снять роль: «Пользователи» → действие «Снять роль модератора» (убирает привязки и 2FA).

## Приглашения
Модератор в разделе «Приглашения домов» создаёт код для дома (срок до 60 дней, по умолчанию 14). Код показывается один раз, одноразовый, его можно отозвать.

## Если потерян телефон
- Если телефон потерян, а резервные коды есть: войдите по резервному коду (он сработает один раз). Кнопки перевыпуска кодов в интерфейсе пока нет: если коды заканчиваются, попросите главного администратора сбросить защиту и настройте её заново.
- Если нет ни телефона, ни кодов: главный администратор сбрасывает защиту модератора действием в «Пользователях». Если потерял доступ сам главный администратор: `python manage.py reset_2fa <e-mail>` на сервере.

## Журнал аудита
Раздел «Журнал аудита» виден только главному администратору. Записи нельзя изменить или удалить.
