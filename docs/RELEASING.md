# Версии, выпуск и откат

## Версии
`MAJOR.MINOR.PATCH`; предварительные — `0.8.0.dev1`. Версия записывается в `VERSION`, `backend/config/version.py` и `CHANGELOG.md` — расхождение ловит проверка.

## Выпуск
1. Изменения идут через ветку и pull request; в `main` — только при зелёном CI.
2. Обновить `VERSION`, `version.py`, `CHANGELOG.md`.
3. Поставить тег: `git tag v0.8.0.dev2` и `git push origin v0.8.0.dev2`.

## Откат
- **Код:** развернуть образ предыдущего тега.
- **База:** перед каждым выпуском — бэкап. Миграции пишутся в порядке «расширить → переключить → удалить», чтобы предыдущий код работал на новой схеме.
- Откат в Git: `git revert <коммит>` (история сохраняется).
