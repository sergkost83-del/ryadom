# Изображения приложения

Готовые к использованию лёгкие файлы лежат в `design/assets/` (WebP и несколько PNG, около 4,6 МБ). Оригиналы от дизайнера (PNG/JPG, около 32 МБ) в репозиторий не кладутся: храните их у себя. Опись всех файлов с контрольными суммами: `design/assets/manifest.json`.

## Как пересобрать
`python tools/build_app_assets.py --src <папка с оригиналами> --out design/assets` (нужен Pillow). Скрипт вырезает аватары по кругу, убирает «дымку» фона, сжимает в WebP и обновляет опись. Папка оригиналов: `brand/`, `icons/`, `illustrations/`, `covers/`, `avatars/`, `placeholders/`.

## Соответствие данным
- Аватары: поле `avatar_id` пользователя (1–8) → `avatars/avatar_<id>_512.webp` (профиль) и `_256.webp` (списки).
- Обложки ЖК: `covers/cover_<slug ЖК>_1600.webp` (шапка) и `_800.webp` (карточка); для ЖК без обложки `cover_generic_*`.
- Иконки разделов: `icons/icon_<раздел>.webp`; пока нужны `rides`, `parking`, `chat`, `support`, `notices`, остальные для следующих версий.
- Знак, иконка приложения, значок уведомлений Android, значок для Google Play, экран запуска: `brand/`.

## Правила
Без текста в картинках, без чужих брендов, без знаков такси на машинах, на изображениях только взрослые.

## Не включено (ждёт переделки)
- `onboarding_2` (обрезан по краю).
- Рекламные картинки для магазинов и соцсетей (в слове «РЯДОМ» буква «Д» заменена домиком; соберём в коде настоящим шрифтом).

## Права
Изображения сгенерированы в ChatGPT. До публичного запуска нужно проверить условия сервиса для коммерческого использования на дату публикации, сохранить копию условий и по возможности запросы (промпты).
