# Принятые решения

1. **Django + DRF + PostgreSQL.** Админка для модерации, миграции, права из коробки; ограничения целостности в БД (защита от двойных броней и дублей).
2. **UUID во внешних идентификаторах.** Нельзя перебирать подряд.
3. **Регистрация только 18+ на MVP.** Тип аккаунта и версионирование согласий закладываются расширяемыми; семейные аккаунты — только после правовой проработки.
4. **Подтверждение адреса:** код-приглашение дома + ручная проверка модератором. Сканы документов не принимаем и не храним.
5. **Попутчик без цены перевозки** в модели и интерфейсе MVP. Любая компенсация расходов — после заключения юриста.
6. **Хостинг не привязан к провайдеру.** Предварительно Yandex Cloud (данные в РФ); окончательно — после оценки стоимости. Платная инфраструктура не покупается без согласования.
7. **Основная проверка — GitHub Actions.** Docker на компьютере разработчика не обязателен.
8. **Оператор персональных данных на первом этапе — ИП владельца проекта.** Уведомление в Роскомнадзор подаётся до начала обработки данных реальных жителей.
9. **Клиент:** React Native + Expo (TypeScript), веб-сборка из того же кода.
11. **Двухфакторная защита сотрудников** через приложение-аутентификатор (TOTP, Яндекс Ключ) с резервными кодами; обязательна для всех, кто входит в админку.
12. **Модератор работает только со своим ЖК**; на ЖК может быть несколько модераторов; привязку делает только главный администратор; проверка на сервере.
13. **Журнал аудита** действий с персональными данными: пользователь, время, действие, изменения; без секретов и без e-mail жителей; читает только главный администратор. Срок хранения журнала и состав записей согласовать с юристом.
14. **Код приглашения дома**: одноразовый, со сроком, с отзывом; хранится хэш. Смена адреса — заявка, решает модератор ЖК назначения или главный администратор.
10. **Отдельный репозиторий** `ryadom`; старый `lesya-mesh-web` остаётся архивом.
15. **Изображения в репозитории только в облегчённом виде** (WebP, около 4,6 МБ) с описью и контрольными суммами; тяжёлые оригиналы хранятся вне репозитория.
16. **Запуск: Docker Compose + Caddy + PostgreSQL на одном сервере**, копии шифруются `age`, приватный ключ копий не хранится на сервере, срок хранения копий 30 дней (согласовать с юристом).
17. **Клиент на Expo (React Native + TypeScript)**: одна кодовая база для iPhone, Android и веба. Токены: защищённое хранилище системы на телефоне, localStorage в вебе. В приложении только работающие функции: неготовые разделы не показываются.
18. **Чаты: два вида (дом и ЖК), доступ только по подтверждённому адресу.** Блокировка скрывает автора только для блокирующего. Текст сообщений не копируется в журнал аудита.
