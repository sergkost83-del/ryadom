# Принятые решения

1. **Django + DRF + PostgreSQL.** Админка для модерации, миграции, права из коробки; ограничения целостности в БД (защита от двойных броней и дублей).
2. **UUID во внешних идентификаторах.** Нельзя перебирать подряд.
3. **Регистрация только 18+ на MVP.** Тип аккаунта и версионирование согласий закладываются расширяемыми; семейные аккаунты — только после правовой проработки.
4. **Подтверждение адреса:** код-приглашение дома + ручная проверка модератором. Сканы документов не принимаем и не храним.
5. **Попутчик без цены перевозки** в модели и интерфейсе MVP. Любая компенсация расходов — после заключения юриста.
6. **Хостинг не привязан к провайдеру.** Предварительно Yandex Cloud (данные в РФ); окончательно — после оценки стоимости. Платная инфраструктура не покупается без согласования.
7. **Основная проверка — GitHub Actions.** Docker на компьютере разработчика не обязателен.
8. **Оператор персональных данных на первом этапе — ИП владельца проекта.** Уведомление в Роскомнадзор подаётся до начала обработки данных реальных жителей.
9. **Клиент:** React Native + Expo (TypeScript), веб-сборка из того же кода.
10. **Отдельный репозиторий** `ryadom`; старый `lesya-mesh-web` остаётся архивом.
