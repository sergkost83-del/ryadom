# Проверка модерации в Codespaces (вживую)

Нужно: Codespace с запущенным сервером (`docker compose up --build`), публичный порт 8000 и телефон с приложением-аутентификатора (Яндекс Ключ или другой TOTP).

## 1. Главный администратор
В терминале сервера (вкладка docker):
```
docker compose exec backend python manage.py createsuperuser
```
Введите e-mail и пароль (не короче 12 символов). Это учётная запись для админки, не житель.

## 2. Вход и защита
1. Откройте `https://ВАШ-ПОРТ-8000.app.github.dev/admin/` и войдите.
2. Система предложит настроить защиту: отсканируйте QR в Яндекс Ключе или введите ключ вручную, затем 6-значный код.
3. Сохраните 10 резервных кодов (показываются один раз).

## 3. Модератор ЖК
1. Модератор должен быть жителем: зарегистрируйтесь в приложении вторым e-mail (по коду приглашения из `seed_demo`).
2. В админке: «Пользователи» → выберите модератора → действие «Назначить модератором» → Выполнить.
3. «Привязки модераторов» → «Добавить»: пользователь — модератор, ЖК — «Новые горизонты» → Сохранить.
4. Задайте модератору пароль (он нужен для входа в админку):
   ```
   docker compose exec backend python manage.py set_staff_password ЭЛ_ПОЧТА_МОДЕРАТОРА
   ```
5. Выйдите из админки и войдите модератором. При первом входе он настраивает свою защиту.

## 4. Подтверждение адреса жителя
1. Житель регистрируется по адресу (без кода): его заявка «на проверке».
2. Модератор: «Заявки жителей» → выберите заявку → действие «Подтвердить адрес» → Выполнить.
3. В приложении жителя обновите главную: статус «Адрес подтверждён» и объявления дома.

## 5. Что проверить
- Модератор видит жителей только своего ЖК. Чужой ЖК в списках не появляется.
- «Привязки модераторов» и «Журнал аудита» для модератора недоступны (403).
- Модератор может скрыть сообщение в чате своего ЖК (раздел «Сообщения чатов» → «Скрыть»). В журнале появится запись без текста сообщения.
- Журнал аудита виден только главному администратору.

## Если что-то не так
- Нет кода входа в приложении: смотрите вкладку docker, там письмо с кодом.
- Забыли пароль модератора: повторите команду `set_staff_password`.
- Потеряли телефон и резервные коды: `docker compose exec backend python manage.py reset_2fa ЭЛ_ПОЧТА`.
