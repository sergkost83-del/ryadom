# Сквозной сценарий M2 (браузер)

Автотест `client/e2e/tests/chat.spec.ts` в CI:
1. Регистрирует двух соседей из разных домов одного ЖК по одноразовым кодам приглашения (`seed_demo`).
2. Код входа берётся из письма, которое сервер пишет в файл (режим разработки).
3. Соседи переписываются в общем чате комплекса и видят ответы друг друга после обновления страницы.
4. Отдельный сценарий: сообщение удаляется автором и исчезает у соседа.

Проверка в CI: задание «Сквозной сценарий (браузер)». Отчёт с видео и скриншотами при падении — в артефакте `e2e-reports`.

Пункт приёмки M2 «сквозной браузерный сценарий» считается выполненным, когда это задание зелёное.
