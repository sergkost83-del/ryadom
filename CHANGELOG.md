# Журнал изменений

Формат версий: `MAJOR.MINOR.PATCH`, предварительные — `.devN` (например, `0.8.0.dev1`).
Версия 1.0.0 — запуск закрытого пилота.

## 0.8.0.dev1 — каркас нового проекта

Новый проект на Django + PostgreSQL вместо прототипа v0.7.0.2 (подробности: `docs/LEGACY_MAP.md`).

- Каркас репозитория, настройки dev/test/prod через переменные окружения.
- Пользователь (`identity.User`): e-mail как логин, UUID, пароль только у сотрудников.
- Справочник: регион → населённый пункт → ЖК → улица → дом; стартовые данные из v0.7.0.2 (3 ЖК, 23 дома).
- Проверка работоспособности `/api/v1/health/`.
- Автоматические проверки: GitHub Actions, `CHECK_ALL.bat`.
- Вход по коду, согласия, профиль и права доступа — следующие версии M1.
